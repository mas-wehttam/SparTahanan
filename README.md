# SparTahanan

**A Student Accommodation Guide to Dormitories and Boarding Houses Near BatStateU**

SparTahanan is a student-focused accommodation directory intended to help Batangas State University students discover and compare dormitories and boarding houses near their respective campuses.

## Open the website

Serve the project folder with a static web server and open its root `index.html`. The site uses plain HTML, CSS, and JavaScript and has no build step. The layout is designed for desktop viewing.

## Page folders

| Folder | Page |
| --- | --- |
| `home/` | Home and featured properties |
| `accommodations/` | Search, filters, property details, saved listings, and comparisons |
| `list-property/` | Property submission form |
| `about/` | About, contact, reports, and feedback |

Each folder has an `index.html` for the page content, a `styles.css` for its appearance, and a `script.js` for its behavior. The directory's sample listings are in `accommodations/properties.js`. Images and icons are in `assets/`. The four HTML files at the project root forward old links to the page folders.

Saved listings, comparison choices, and demo form submissions stay in the current browser.
